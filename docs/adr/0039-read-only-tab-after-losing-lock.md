# ADR-0039. 편집 잠금을 잃은 탭은 안내만 보이고, 다운로드는 되지만 다운로드 기록은 저장하지 않는다

- 상태: 승인
- 날짜: 2026-09-28
- 보충: ADR-0024

## 배경

ADR-0024는 편집 권한(편집 잠금)을 브라우저 탭 하나에만 주고, 다른 탭이 "여기서 열기"로 권한을 가져가면 원래 탭은 읽기 전용이 된다고 정했다. 그 탭의 안내 문구와, 그 탭에서 할 수 있는 일(다운로드 등)은 정하지 않았다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 안내만 보이고 버튼은 두지 않는다. 다운로드는 되지만 다운로드 기록은 저장하지 않는다 | 두 탭이 IndexedDB에 번갈아 쓰지 않는다. 사용자는 지금 보이는 내용을 받아 갈 수 있다 | 이 탭에서 다시 편집하려면 새로고침해야 한다 |
| B. 안내에 "여기서 다시 열기" 버튼을 둔다 | 새로고침 없이 권한을 되찾는다 | 두 탭이 버튼으로 권한을 계속 주고받을 수 있고, 가져올 때 저장본을 다시 읽는 흐름이 하나 더 생긴다 |
| C. 다운로드도 막는다 | 읽기 전용 탭이 아무것도 바꾸지 않는다 | 다운로드는 편집이 아닌데도 막혀, 보이는 내용을 받을 방법이 없다 |

## 결정

**A를 택한다.**

- 안내 제목은 "다른 탭으로 편집이 넘어갔어요", 본문은 "이 탭은 읽기 전용이에요. 여기서 다시 편집하려면 새로고침한 뒤 '여기서 열기'를 누르세요."다. 버튼은 없다.
- 읽기 전용 탭에서도 다운로드할 수 있다. 다운로드 기록은 IndexedDB에 저장하지 않는다.

## 근거

- 잠금을 잃은 탭은 IndexedDB에 쓰지 않아야 두 탭의 저장이 서로 덮어쓰지 않는다(ADR-0024). 다운로드 기록도 저장본의 일부다.
- 새로고침하면 ADR-0024의 흐름("여기서 열기")을 그대로 따른다. 같은 일을 하는 두 번째 길을 만들지 않는다.

## 결과

- 문구는 앱의 문구 모듈에 둔다(ADR-0015).
- 다운로드 흐름은 편집 잠금이 있는 탭에서만 기록을 저장한다.
