# ADR-0016. 가운데에 workspace 계층을 두고, 패키지끼리는 서로 import하지 않는다

- 상태: 승인 (의존 규칙은 ADR-0022, 패키지 이름은 ADR-0023, `writeZip` 쓰기 방식은 ADR-0037로 일부 대체)
- 날짜: 2026-09-27
- 수정: ADR-0003의 패키지 목록에 `packages/workspace`를 추가한다

## 배경

ZIP에서 꺼낸 바이트를 앱이 Monaco에 바로 넣으면 ZIP 코드와 에디터 코드가 서로 얽힌다. ZIP 쪽을 고치면 에디터 쪽도 함께 고쳐야 하고, ZIP이 아닌 곳(폴더 업로드, 원격 저장소 등)에서 파일을 가져오려면 연결 코드를 다시 짜야 한다. 에디터와 Monaco 연결 코드는 다른 서비스에서도 쓸 수 있어야 한다(ADR-0003).

## 선택지

ZIP과 에디터를 어떻게 이을지 두 가지를 비교했다.

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 앱이 zip과 editor를 직접 잇는다 | 계층이 하나 적다 | 트리·변경 사항 관리가 앱 코드에 흩어진다. 파일 출처를 바꾸려면 앱 코드를 다시 짜야 한다 |
| B. 가운데에 가상 파일 시스템(workspace)을 두고, 파일 출처는 인터페이스로 받는다 | 각 패키지가 한 가지만 안다. 파일 출처와 에디터를 각각 바꿔 끼울 수 있다 | 패키지가 하나 늘어난다 |

## 결정

**B를 택한다.**

### 패키지별 책임

| 패키지 | 아는 것 | 모르는 것 |
|---|---|---|
| `zip` | ZIP 형식 읽기·쓰기 | 트리, Monaco |
| `workspace` | 경로별 파일, 트리, 추가·삭제·이름 변경, 구조 버전, 내보내기 계획 | 파일이 어디서 오는지, Monaco |
| `editor` | Monaco model 관리, 에디터 화면 붙이기 | ZIP, workspace, React |
| `file-kind` | 바이트로 파일 종류 판단 | 나머지 전부 |
| `apps/web` | 위 패키지를 이어 붙이는 방법 | — |

파일 트리를 만드는 코드는 `zip`이 아니라 `workspace`에 둔다. ZIP의 항목 목록과 사용자가 보는 트리를 분리한다.

### 연결 지점 (인터페이스 초안)

- **파일 출처(`FileSource`)**: `workspace`가 모양을 정의한다. 항목 목록, 앞부분 읽기, 전체 읽기를 제공한다. `zip`은 `workspace`를 import하지 않고, TypeScript의 구조적 타입 호환으로 이 모양을 맞춘다.
- **`zip`**: `openZip(Blob)`으로 목록만 읽고, 경로별 앞부분 읽기·전체 읽기·원본 압축 바이트 꺼내기를 제공한다. `writeZip`은 "원본 복사" 또는 "새 내용" 항목을 받아 스트림으로 쓴다. `Blob.slice()`로 필요한 범위만 읽는다.
- **`workspace`**: `createWorkspace(source)`로 만들고, 트리 조회, 추가·삭제·이름 변경, 구조 버전, 읽기, 내보내기 계획(파일마다 원본 복사·재압축·제외)을 제공한다.
- **`editor`**: `createModelRegistry(monaco)`로 Monaco 객체를 주입받는다. 경로별로 파일을 열고, 텍스트를 읽고, 수정 여부와 다운로드 기준(ADR-0009)을 표시하고, 이름을 바꾸고, 닫을 수 있으며, 수정 상태를 구독할 수 있다. 에디터 화면은 그룹마다 따로 붙인다(ADR-0007).
- 모든 읽기 함수는 비동기다. 같은 인터페이스를 Web Worker 안에서 구현해도 호출하는 쪽이 바뀌지 않는다.

세부 시그니처는 설계 문서에서 정한다.

### 의존 규칙

```
apps/web  → workspace, zip, editor, file-kind
workspace → (없음)
zip       → (없음)
editor    → monaco-editor (peer)
file-kind → (없음)
```

패키지끼리는 서로 import하지 않는다. 연결은 `apps/web`의 business hook에서만 한다. 이 규칙은 린트의 import 제한 규칙으로 강제하고, 어긴 import는 CI에서 막는다.

## 결과

- 폴더 업로드처럼 다른 파일 출처를 붙이려면 `FileSource` 구현 하나만 추가하면 된다.
- Monaco를 다른 에디터로 바꾸려면 `editor` 패키지만 바꾸면 된다.
- 내보내기 계획은 순수 데이터라 ZIP 쓰기 없이 단위 테스트할 수 있다.
- 패키지가 다섯 개(`zip`, `workspace`, `editor`, `file-kind`, `apps/web`)가 되므로, 설정과 README 구조도도 이에 맞춰 바꿔야 한다.
