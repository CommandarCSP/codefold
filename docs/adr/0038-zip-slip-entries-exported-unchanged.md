# ADR-0038. `..`이 든 항목은 경고 없이 내려받은 ZIP에 원본 그대로 넣는다

- 상태: 승인
- 날짜: 2026-09-28

## 배경

ZIP 안의 경로에 `..`이 들어 있으면(zip-slip), 압축 프로그램에 따라서는 ZIP 밖의 위치에 파일을 쓰기도 한다. virtual-fs는 이런 항목을 트리에 넣지 않고 숨긴다. 다운로드할 때는 원본 그대로 복사한다. 앱이 이 사실을 사용자에게 알릴지는 정하지 않았다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 경고하지 않는다. 원본 그대로 복사하는 동작은 그대로 둔다 | 받은 ZIP에 올린 ZIP의 항목이 모두 들어 있다. 알림이 늘지 않는다 | 사용자는 트리에 보이지 않는 위험 항목이 다시 나간다는 것을 모른다 |
| B. 열 때 "보이지 않는 위험 경로 항목 N개가 그대로 다시 나간다"고 알린다 | 사용자가 안다 | 알림이 하나 늘고, 사용자가 할 수 있는 일(빼기)이 없어 안내만 남는다 |
| C. 다운로드할 때 빼 버린다 | 받은 ZIP이 안전해진다 | "고치지 않은 것은 원본 그대로"를 어기고, 사용자가 모르게 항목이 사라진다 |

## 결정

**A를 택한다.** `..`이 든 항목은 트리에 보이지 않고, 받은 ZIP에 원본 그대로 들어간다. 앱은 경고하지 않는다.

## 근거

- 이 앱은 ZIP을 풀어 디스크에 쓰지 않는다. 위험은 받은 ZIP을 다른 프로그램으로 풀 때 생긴다. 그런데 그 항목은 사용자가 올린 원본에 이미 있던 것이다.
- 앱이 사용자 모르게 항목을 빼면, "고치지 않은 것은 원본 그대로"라는 약속(ADR-0009)이 깨진다.

## 결과

- 앱에 zip-slip 알림을 두지 않는다. README의 한계 절에 이 동작을 적는다.
- 나중에 경고가 필요해지면 virtual-fs가 위험한 경로로 숨긴 항목(이유 `unsafe`)을 세어 알림 하나로 붙일 수 있다.
