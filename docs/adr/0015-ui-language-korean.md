# ADR-0015. 화면 문구는 한국어로 쓰고 한 곳에 모은다

- 상태: 승인
- 날짜: 2026-09-27

## 배경

버튼, 안내, 오류 메시지 같은 화면 문구의 언어를 정해야 한다. 처음 대상으로 삼는 사용자는 한국어 사용자이고, 문서와 ADR도 한국어다.

## 선택지

화면 문구 언어에 따라 세 가지를 비교했다.

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 한국어 | 사용자와 문서 언어가 일치한다 | 다국어가 필요해지면 구조를 확장해야 한다 |
| B. 영어 | 개발 도구 화면에서 흔하다 | 한국어 문서와 섞여 일관성이 떨어진다 |
| C. 한국어·영어 전환 | 다국어를 바로 지원한다 | 번역 라이브러리만큼 번들이 커지고, 문구를 두 벌 관리해야 한다. 지금 대상 사용자에게는 필요하지 않다 |

## 결정

**A를 택한다.**

- 화면 문구는 컴포넌트에 직접 쓰지 않고 `apps/web`의 문구 모듈 한 곳에 모은다. 변수가 들어가는 문구는 함수로 둔다(예: "받지 않은 변경 3개").
- 문구 모듈의 키 구조를 언어와 무관하게 설계해, 다국어가 필요해지면 언어별 모듈만 추가해 확장한다.

## 결과

- 문구를 한 파일에서 검토하고 고칠 수 있다.
- 번역 라이브러리 없이 번들을 작게 유지한다.
